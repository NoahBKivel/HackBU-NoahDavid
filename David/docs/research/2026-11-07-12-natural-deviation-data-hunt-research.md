## NEW (post-cutoff) findings
### A. Natural / on-policy hacking
- **ai-safety-institute/reward-hacking-olmo3.1-32b-kl0.0-seed2-rollouts** https://huggingface.co/datasets/ai-safety-institute/reward-hacking-olmo3.1-32b-kl0.0-seed2-rollouts (lastMod 2026-07-01). Apache-2.0. ~25.7k rows, 1.38GB parquet + raw Inspect .eval. GRPO of OLMo-3.1-32B in `codecontests_reward_hacking` (exploitable pytest graders). Fields: messages, reasoning, response, training_passed, passed, actually_solved, reward_hacked, rh_always_equal, rh_exit, rh_conftest, cot_mentions_hack (keyword proxy only), hack_config. Labels deterministic (exploit used). 401 training steps sampled every 10 -> clean-early vs hacked-late contrast. Card cites "Natural Emergent Misalignment from Reward Hacking". Caveats: single-turn competitive programming, not Claude-Code style; UNVERIFIED whether prompt discloses hack options (config has allow_* flags). Card: transcripts deceptive/misaligned by design, not for deployment (research notice, not anti-training). Teaches test tamper (conftest), special-casing (always_equal), early exit. Sibling: https://huggingface.co/datasets/ai-safety-institute/reward-hacking-olmo3.1-32b-kl0.02-seed2-rollouts (same schema).
- **gutenbergpbc/aria-reward-hacking** https://huggingface.co/datasets/gutenbergpbc/aria-reward-hacking (2026-07-20). 51,200 rows, 95MB; license "other", upstream declares none (check before training). Qwen3-4B GRPO `no_intervention`, test-overwrite loophole; system prompt asks only for correct code => natural (inferred, not documented). Fields: messages, message_spans, step, score, is_reward_hack_strict/loose, is_test_modification_harmful, category_5way (correct 10,560; correct+attempted hack 8,130; successful hack 11,536; failed hack 1,189; incorrect 19,785). Reproduction of Aria's LessWrong "Steering RL Training" run (code ariahw/rl-rewardhacking). 5k subset: gutenbergpbc/aria-reward-hacking-5k. Single-turn. Use strict flag (loose count equals harmful-test-mod count, 20,855).
- **Goodfire/reward-hack-data** https://huggingface.co/datasets/Goodfire/reward-hack-data (2026-10-08, 1.7k dl). 2.61GB JSON; paper arXiv 2609.19101 https://arxiv.org/html/2609.19101. Kimi K3, GLM 5.2, Qwen 3.8 Max on SWE-bench Verified, DeepSWE, ImpossibleBench (LLM judge x3 consensus; reported hack rates ~50-95%, suspiciously high, audit), tau3-bench and ShoppingBench (single-pass generic monitor, firing 4-8%). Fields: id, env, traces[0].{task,nodes,metrics,rewards,info}; labels join on node_index. License not stated; natural-vs-prompted not stated (benchmark rollouts without hack instruction, likely natural, UNVERIFIED). 3 runs `_PARTIAL`; viewer broken. Teaches multi-turn test tamper/special-casing; tau3/Shopping give non-coding deviation negatives.
- **HVTB (Hack-Verifiable Terminal Bench)** arXiv 2608.22103 https://arxiv.org/abs/2608.22103 ; https://majoroth.github.io/hack-verifiable-environments/hvtb ; traces https://hub.harborframework.com/organizations/hack-verifiable-environments . 2,225 traces / 89 envs; Claude Code (opus-5), Codex (gpt-5.6-sol), gemini-cli (3.1-pro), kimi-k3, glm-5.2. Labels deterministic (inotify on planted admin/ dir). Settings: Ablation (unmodified prompt = natural) and L0-L3 (L3 explicit prohibition => explicit-instruction violations, M1). Format/license unstated.
- **Sengim/impossiblebench-rollouts** https://huggingface.co/datasets/Sengim/impossiblebench-rollouts (2026-10-29). 210 rows, 7.4MB, no card/license; qwen3.8-27b; fields variant, score (I/C), test_modified (bool, cheap deterministic label), test, original_test, tools, messages. ImpossibleBench = impossible-by-design, not natural. Also natemacfadden/impossiblebench-pairs-unofficial (UNVERIFIED).
- **lucabaroni/rlvr-reward-hacking-transcripts** https://huggingface.co/datasets/lucabaroni/rlvr-reward-hacking-transcripts (+ mid-checkpoint, + scale-no-conftest-20260909 variants, 10k-100k rows). 900 trajs, Qwen3.5-9B / GPT-OSS-120B / Nemotron-3-Super; behavioral + blinded CoT judgments; hack rates 62-98%. PROMPTED: models told of exploits and told not to use them => explicit-instruction-violation data (M1), NOT natural. Composite license (trajectories CC BY 4.0). Contains executable exploit code.

### B. Real sessions with user pushback (M1, L7, L4)
- **SALT-NLP/SWE-chat v2** https://huggingface.co/datasets/SALT-NLP/SWE-chat (paper arXiv 2604.20779 https://huggingface.co/papers/2604.20779). v2 2026-10-02: 17,968 sessions, 229,909 user prompts, 707 repos, 62,333 commits, ~47GB (v1 2026-04-29: 5,851 sessions). odc-by; gated (agree to share HF info); removal process; no anti-training clause found. LLM-annotated labels: prompt_pushback {correction, rejection, failure_report, non_pushback}, prompt_intent, session_success 0-100, user_persona (Expert Nitpicker, Vague Requester, Mind Changer). Paper: pushback in 44% of turns. Natural. Teaches M1, L7 (correction then next agent turn), L4 (rejection after substitution).
- **davanstrien/agent-trace-sentiment** https://huggingface.co/datasets/davanstrien/agent-trace-sentiment : 8.95k user messages, MIT, LLM labels NEGATIVE/NEUTRAL/POSITIVE + reason, 33 source datasets; fields session_id, turn, nTurns, normPos, n_errors. Noisy; use as frustration index. 1h.
- **TonyDzi/agent-sessions** https://huggingface.co/datasets/TonyDzi/agent-sessions (2026-11-07): 48,813 records, 509M words, 7.5GB, CC BY 4.0 (quoted tool output keeps upstream license). Claude Code 35,095 / Codex 8,970 / ChatGPT / deep research. Rendered text, reasoning omitted, PII masked. NO behavior labels; likely few contributors (UNVERIFIED). Large natural Claude Code corpus; needs own LLM labeling (~6-8h).
- Unlabeled agent-trace dumps (HF Agent Traces docs https://huggingface.co/docs/hub/en/agent-traces): thomasmustier/*-sessions (pi agent, ~12 repos), allallallal/*-omp-sessions, taalyelxor/vlap4p-agent-sessions (Claude Code), peteromallet/my-personal-codex-data (1,297 Codex sessions; DataClaw https://github.com/peteromallet/dataclaw), cfahlgren1/agent-sessions-list, PotatoHD/agent-coding-traces-public (derived SWE-bench-Pro/R2E runs). Pi/omp formats differ from Claude Code.
- **"How Coding Agents Fail Their Users"** arXiv 2605.29442 https://arxiv.org/abs/2605.29442 : 20,574 real sessions, 1,639 repos, annotated form/cause/cost/resolution (7 forms incl. constraint violation, inaccurate self-reporting). No data link on abs; source unnamed (check full text). Taxonomy usable as label schema regardless.
