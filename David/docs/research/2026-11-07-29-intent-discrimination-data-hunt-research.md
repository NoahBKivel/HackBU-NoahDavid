# Intent-discrimination data hunt for the Kev-4B user-intent monitor

Date: 2026-11-07. Scope: public, labelled data that teaches user-intent discrimination in the goal-inference sense: what the user wants, whether a response or action satisfies it (fully / partially / not), whether it follows constraints, whether the assistant should have asked, and whether intent shifted. Each entry was checked on its own page unless marked UNVERIFIED. Split: Part A is the known baseline (pre-2026 or well-known). Part B is post-cutoff / 2026 discovery.

Notation. Decision types follow Kev-4B's System One schema: `noul` = yes/no, `choice` = named options, `score` = ordered levels ([jaredpalmer/kev-4b](https://huggingface.co/jaredpalmer/kev-4b)). "Conv h" = estimated hours to convert to typed decisions. Provenance: H = human, LLM = model label, R = rule/test.

## 0. Facts about Kev-4B that change the plan

- Kev-4B = LoRA + pointer head on frozen Qwen/Qwen3.5-4B-Base; Apache-2.0; Kev 1.0 published 2026-09-24. Types: choice / score / noul. [card](https://huggingface.co/jaredpalmer/kev-4b)
- Its training already includes a devtools-v1 slice (5,320 records) from **CodeReviewer, CommitPackFT, FlakeFlagger, Aegis**. So CodeReviewer and commit-message sets add little that is new. When2Call and prompt injection are held out as evaluation-only sources. [card](https://huggingface.co/jaredpalmer/kev-4b)
- The card reports no intent or helpfulness evaluation. Breadth-v1 test accuracy is 0.690 (Jev: 0.757). [card](https://huggingface.co/jaredpalmer/kev-4b)
- Degradation guard: the card lists its base recipe (decision-v7, ten public classification sets) and hard-v1 skills. Replay from these during the intent fine-tune is the obvious anti-forgetting mix. The recipe files themselves were not checked: UNVERIFIED.

## Ranked top-8 by expected value for broad intent discrimination

Criteria: label quality × breadth × closeness to coding-agent traces × licence, minus degradation risk.

1. **HelpSteer3** (preference + feedback + principle). Human, 4 domains, 8,857 code items, CC-BY-4.0. Gives choice, score and noul (principle) questions at once. The principle subset is already state+question→yes/no. ~4 h.
2. **SWE-bench annotations** (OpenAI screen, 1,699 issues / 5,097 annotator rows). Human professional developers, real issues. Teaches "is this request specified enough to act on?" and "do the checks test what was asked?". ~3 h. Keep the ids out of evals.
3. **SWE-chat v2**. Real coding-agent sessions with pushback labels, so it is the closest match to deployment. Labels are LLM-made, so relabel ~1–2k with a strong teacher or humans and use soft targets. Gated, ODC-BY. ~6 h.
4. **WildFeedback**. ~1M real-user turns with a SAT/DSAT label and a **State** label (refinement / new topic / feedback). The only large intent-shift source. GPT-4o labels (DSAT κ 0.50): down-weight. ~3 h.
5. **Arena human votes** (140k, filtered to category_tag IF + is_code; plus RepoChat 4k and Expert 5k). Broad real-user preference. The `both_bad` label maps to "satisfied neither". ~3 h. Control for length and style.
6. **Clarification contrast bundle**: LHAW (285 paired, validated criticality) + IN3 (1,369 agent tasks, human-adapted) + Ambig-SWE (500 paired issues) + HumanEvalComm (164 × variants). Paired full/underspecified items limit shortcuts. LHAW benign teaches not over-asking. ~6 h combined.
7. **CLAMBER + ClariQ**. Broad clarification-need taxonomy (12K, expert-checked, 92.4%) and human 1–4 need scores. Non-coding breadth for "should ask". ~3 h. Licences unstated: confirm first.
8. **HelpSteer2**. 21k human 5-attribute scores. Cheap bulk "score how well it satisfies the request". ~2 h. Watch overlap with HelpSteer v1 in tasksource-jev.

Use as eval only, do not train: LLMBar (419), RewardBench 2 Precise IF / Focus, MT-Bench human, HiL-Bench, MTAC-IFBench (zh), TRAIL (licence forbids training judge systems), AgentRewardBench.

Down-weight or avoid: UltraFeedback and Skywork-80K (LLM / RM labels, judge bias; Skywork has no licence), MAST (LLM judge), SGD (rule intents), JL-ActionBoundary / swe-clarify / SpecBench (synthetic), WebDev Arena (no-redistribution licence), PRISM responses (NC), JevAgentHarness sets (NC; AgentDecision-train replays When2Call train, and Kev holds When2Call out for eval).

Degradation guard for every source: mix with Kev's existing recipe replay (decision-v7 / hard-v1 / devtools-v1) or with licence-filtered tasksource-jev-typed-decisions rows. Rebalance yes/no priors (IN3 is 80% vague; the SWE annotation ensemble skews towards severe labels). Cap rule-verified format constraints (IF-RLVR) so the model does not learn "intent = surface format".

## Categories with nothing usable

- **Human per-step "did this action do what the user asked" labels on coding-agent traces:** none public. Nearest options: SWE-chat (LLM + 100 human gold), AgentGlass (human, failures only), Misalignment Atlas (LLM).
- **Copilot / Cursor / IDE acceptance labels:** nothing released. Copilot Arena only promised a release. AgentLogs has only implicit PR-merge signals and raises consent problems.
- **Natural-language goal / plan recognition:** nothing usable. Existing sets are PDDL or egocentric video.
- **Human-labelled intent shift:** IntentDelta exists but is unreleased (UNVERIFIED). Released options are LLM-labelled (WildFeedback) or generated (UserIntentBench, evolving-intent).
- **Intent / request-satisfaction data already in Jev/Kev format:** none dedicated. tasksource-jev-typed-decisions holds only AmbigNQ-clarifying-question and HelpSteer v1 attributes. JevAgentHarness sets cover tool and stop decisions only.
